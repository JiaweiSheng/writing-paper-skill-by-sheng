# Revision Workflow

Use this guide when the user provides prose, reviewer feedback, a word limit, or
a request to polish or rewrite.

## Select the Revision Depth

- **Copyedit:** repair language while preserving argument, paragraph order,
  terminology, citations, and claim strength.
- **Line edit:** improve sentence focus, cohesion, transitions, and redundancy;
  preserve technical content and evidence.
- **Structural revision:** reorder or merge paragraphs, repair the gap-to-method
  chain, align sections, and rewrite contribution framing.
- **Substantive revision:** alter claims, interpretation, taxonomy, or technical
  framing only when the user asks or supplied evidence clearly requires it.

Do not silently perform a deeper revision than requested. If local polish cannot
repair a logical defect, improve what is safe and flag the underlying issue.

## Preserve Invariants

Unless explicitly asked, retain citations and LaTeX commands, equation meaning,
cross-reference labels, numeric values, technical qualifiers, acronym expansions,
and chosen method/module names. Do not delete a condition that narrows a claim.

## Revise in Passes

1. Reconstruct the intended meaning and mark ambiguity.
2. Ensure each sentence advances the paragraph's main job.
3. Calibrate verbs and scope to supplied evidence.
4. Improve old-to-new information flow and add only necessary transitions.
5. Remove repeated setup, nominalizations, empty metadiscourse, and misplaced
   implementation detail.
6. Repair grammar and choose precise verbs.
7. Check terms, symbols, names, tense, and cross-references.

## Compression and Expansion

When shortening, protect the research question, gap, mechanism, core method
distinction, evidence scope, and limitations. Compress broad motivation, citation
catalogs, repeated definitions, secondary implementation detail, and duplicate
result narration first. Never trade a precise condition for an overgeneralized
claim.

When expanding, add only a missing function: operational definition, failure
mechanism, solution property, component rationale, experimental control, or
interpretation. Do not inflate with generic importance claims or invented context.

## Reviewer Feedback

Translate each comment into concern, affected claim/section, required evidence or
text change, and status. Fix the manuscript first when possible. Do not imply
that wording resolves a missing experiment. If comments share a root cause,
repair it consistently across sections.

## Deliver the Revision

Return the revised passage first. When useful, add only material changes,
unresolved ambiguities, evidence placeholders, or deliberately softened claims.
